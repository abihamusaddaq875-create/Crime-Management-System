# Crime-Management-System
A simple C++ based Crime Management System developed as an Object-Oriented Programming project. It allows users to add, view, search, update, and delete crime records through a menu-driven interface. The project demonstrates key OOP concepts such as encapsulation, composition, polymorphism, and file handling for permanent data storage.
